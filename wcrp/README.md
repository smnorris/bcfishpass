# WCRP reporting (Canadian Wildlife Federation)

Scripts and queries to enable custom WCRP reporting.
WCRP reporting differs only slightly from general rollups/reports:

1. To emphasize habitat in waterbodies within linear reports:
  	- CO rearing habitat in wetlands is increased by 50% (1.5x)
  	- SK rearing habitat in lakes is increased by 50% (1.5x)

2. Some crossings are excluded

3. Reporting on important side channel barriers is enabled on a case by case basis
